## 一、内核层（lib/，稳定不变）

### 1. Agent 引擎（agent.ts，347 行）
- **ReAct 循环**：`runAgentLoop` 单 agent 循环——模型提 tool call → 执行工具 → 结果回喂 → 再决策，直到模型给出最终答案
- **终止机制**：maxTurns 兜底（16 轮）、run 级取消（signal）、模型层异常/中止受控收尾
- **纯净性（2026-08-25 改造）**：引擎不认识任何业务，业务 hooks 走工厂参数闭包烙（贴 pi）；引擎只传运行时参（signal/onChunk）
- **可观测性边界**：引擎只产出事件（`emit`），展示/落盘由外部消费者完成

### 2. 统一协议（types.ts）
- `AgentMessage`（user/assistant/toolResult/compactionSummary 四类）+ `AgentEvent`（12 种事件）+ SessionStats + TodoItem
- 引擎永远只看 `AssistantMessage` / `ToolCallContent`，provider 字段不出适配层

### 3. 模型适配层
- **`TeachingModel` 接口**（model.ts，8 行）——换大脑的接缝
- **DeepSeekModel**（deepseekModel.ts，637 行）——真实适配器：OpenAI 兼容接口、**真流式**（逐 token delta + tool_call 分片累积）、usage 统计、错误转受控消息
- **MockModel**（mockModel.ts）——离线教学模式（`MOCK_MODE=true`，无 key 可跑）

### 4. 会话记忆（lib/session/）
- **JsonlSessionStore**（store.ts）：JSONL 会话树（id/parentId + leafId，可回溯 switchLeaf）、append-only 落盘、`buildContext()` 从磁盘重建上下文（"内存 = 磁盘"）
- **真摘要压缩（B2，lib/summarize.ts + store 三步）**：`prepareCompaction`（切点/经济性检查）→ `generateSummary`（LLM 结构化摘要，pi 六段格式，失败降级拼贴）→ `commitCompaction`；增量 previousSummary；compactionSummary 独立消息类型（不伪装 user）
- **SessionManager**（manager.ts）：多会话 CRUD、`isValidSessionId` 白名单过滤（幽灵会话防护）

### 5. 权限与安全（lib/permission/ + 相关）
- **路径沙箱**（tools/path-utils.ts）：`resolveInsideWorkspace` 圈住工作区，越界自动拒绝
- **只读命令静态分析**（permission/readonly.ts）：词法近似 + fail-closed（走私语法/写参数拦截），18+ 测试
- **分级审批模式**（approvalMode.ts + permission/）：suggest / bypass / never 三档，运行时切换（抄 pi + CodeWhale）
- **审批日志**（permission/approval-log.ts）：JSONL append + asked/decided 成对校验
- **审批记忆**（permission/approval-memory.ts）：本会话允许 / 一直允许（持久化到 .sessions/approval-rules.json）
- **挂起表**（toolApproval.ts / userAnswers.ts / runControl.ts）：工具确认、提问、run 取消的内存态 Map

### 6. 配置集中（config.ts）
- 唯一配置入口：provider（baseUrl/model/contextWindow）、压缩阈值（window/reserve/keepRecent）、路径、maxTurns、debug 开关——全部支持 env 覆盖

### 7. 可观测性（trace.ts + types.ts）
- L2 轨迹落盘：每个 run 一个 `.traces/*.jsonl`，事件全量记录（调试黑匣子）

## 二、工具集（lib/tools/，11 个工具）

| 工具 | 类型 | 说明 |
|---|---|---|
| list_files | 读 | 列目录（含文件夹标记） |
| read_file | 读 | 读文件 |
| write_file | 写 | 写文件（弹框确认） |
| write_note | 写 | 写工作区笔记（不弹框？——写操作里唯一的轻量路径） |
| edit_file | 写 | 精确替换（oldText → newText，弹框确认） |
| delete_file | 写 | 删除（弹框确认） |
| grep | 读 | 正则搜内容 |
| find | 读 | 按文件名找 |
| bash | 执行 | PowerShell 命令：spawn 流式输出 + 两级终止 + run 级取消（弹框确认）；Windows 乱码根治（cmd + chcp 65001 + EncodedCommand） |
| todo_write | 会话内 | 任务清单整表替换（不进弹框，低危） |
| ask_user_question | 会话内 | 向用户提问（1-4 题），SSE 帧 + 前端作答卡片，跳过/超时降级 |

工具注册 = 工厂函数 + `createToolRegistry` 组装；todo/ask-user 走 hooks 闭包烙（引擎无感）。

## 三、产品层（app/）

### 1. API 路由
- **`api/chat/route.ts`（329 行，E2 重构后薄壳化）**：SSE 主路由，`runPipeline` 编排（approval → model → context → tools → compact → ask-user），每请求组装 registry + hooks
- `api/chat/approve/`：审批回传
- `api/chat/ask-user/`：提问回答回传
- `api/chat/stop/`：run 停止
- `api/chat/approval-mode/`：分级模式运行时切换
- `api/sessions/`：会话 CRUD + 重命名

### 2. 前端（app/components/ + app/lib/）
- **组件**：overture（开场）、nameplate（顶栏）、message-row（消息渲染 + Markdown + 压缩卡片）、trace-rail（事件时间线）、session-list（会话列表）、task-panel（任务面板）、approval-dialog（审批卡片）、approval-mode-switch（三档切换）、ask-user-card（提问卡片）、**ui/menu（第一个原语）**
- **Hooks**：use-agent-run（run 状态编排）、use-sessions（会话列表）、use-sticky-scroll（吸底滚动）
- **纯函数层**：sse.ts（SSE 帧解析）、trace-fold.ts（轨迹折叠）、messages.ts（delta 合并）、keys.ts、format.ts

### 3. 业务接口层（app/services/）
- chat / sessions 两个服务的类型化接口（fetch 全部收口在这里，组件零绕过）

### 4. UI V2（B3 ①②，2026-08-26 完成）
- 全面板尺度升级（34px 命中区 / 15px 正文）、中性壳视觉（纸感退役）、Menu 原语、会话行 DSH 式交互、清空会话功能删除（由新建/删除覆盖）
