## 一、这一批是干什么的

一句话：**给会话装上"工作空间"这个归属** —— 用户先选一个文件夹（它成为一条记录），再在那个文件夹里开会话；会话按工作空间分目录存，侧栏按工作空间分组显示。

五行为什么不能拆开做：

| 行 | 它单独做会发生什么 |
|---|---|
| **C6** 选文件夹 | 选完没地方存 → 白选 |
| **C51** 管理（重命名/打开/删除/组内新建） | 没有记录可管 |
| **C48** 存储分组 | 只有一个"默认工作空间"，分组看不出来 |
| **C49** 列表分组 | 同上：只看到一个组 |
| **C50** 数据根 | 前四样都要落盘，落在哪必须先定 |

⇒ 这是一个**交付单元**，一条分支（`feat/c48-session-grouping`，用户 2026-11-10 指定不改名）。

## 三、开工前的三个"已知坑"（施工时反复看）

1. **5 处拼路径漏一处 = 静默少东西**（导出 404 / 审批写丢 / 轨迹散落）。路径只许从 `lib/session/paths` 来。
2. **`ToolContext` 留在模块作用域 = 所有会话共用第一个工作空间**，不报错。必须配一条跨会话测试。
3. **越界批准不许记忆** —— 一次性通行证，用一次作废。
