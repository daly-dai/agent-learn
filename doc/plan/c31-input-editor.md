## 一、需求（要做什么）

用户原话（2026-09-16）：**「纯文本输入框已经有点跟不上我们的需求了，后面的需求只会越来越多」**。

**现状（已核实）**：输入台就是 `app/page.tsx:414` 的一个裸 `<textarea>`，上方浮一个 `command-menu`（`:399`，过滤 / 键盘逻辑在 `app/lib/use-command-menu.ts`）。而"往输入里塞东西"的手段只有一招 —— **往字符串里插文本**（如插入 `/名字 `）。

**为什么这是坎**：HTML 层面**无法给 `<textarea>` 里的一段文字单独上样式** ⇒ 命令 / 技能 / 文件进到输入框里**永远只是普通文字**：不能当对象删（退格只能一个字一个字删）、不能点、也不携带任何归属信息。
C8 的 skill chip 之所以只能退成"框内上沿贴一个标签"，根子就在这（`doc/plan/c8-skills.md` 第四轮 R4-1；backdrop 高亮被记为升级路径）。

**要改造的核心**：把输入从「**一个字符串**」变成「**一串有类型的片段**」（普通文字 / 命令 / 技能 / `@文件` / 将来的附件…），chip 变成**真对象**。
